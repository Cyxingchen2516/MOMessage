# MOMessage

《心灵终结 3.3.6》（Mental Omega 3.3.6）的客户端界面插件。

一个插件整合了五块界面增强，全部**只影响本地渲染**，联机时对方无需安装。

## 功能

### 1. 消息框增强
- 聊天 / 战役消息居中显示，贴屏幕底部（位置、行数、字体、透明度可配）；
- 打字机效果；
- 雷达事件文字化：基地遭袭、矿车遭袭、发现敌军、单位生产完毕等；
- 点提示文字可把视角跳到事件地点。

### 2. 操作与战斗提示
- 左下角汇总当前操作反馈与战斗提示；
- 可配置行数、宽度、字体、位置。

### 3. 超武侧栏
- 支援技能独立侧栏，可放左侧或右侧，列数/行数可配。

### 4. 攻击范围显示（整合自 MOShowRange）
- 选中单位按 **Alt+Q** 显示范围圈；
- 蓝 = 攻击范围，红 = 最小射程，绿 = 警戒范围；
- 描边圈（中间镂空），不会挡住视线。

### 5. 选中单位信息
- 每个选中单位头顶显示小字：`HP 当前/最大  EXP 百分比`；
- 半透明、字号小，不遮挡原版血条。

## 安装

1. 需要 Syringe（心灵终结自带）。
2. 把 `MOMessage.dll`、`MOMessage.dll.inj`、`MOMessage.ini` 放进游戏根目录。
3. 启动游戏即可。

## 配置

`MOMessage.ini` 里已按功能分段，注释齐全：

```ini
[MsgText]       ; 消息框 / 提示
[UnitHud]       ; 选中单位小字信息
[SWSidebar]     ; 超武侧栏
[ShowRange]     ; 范围圈热键
```

## 说明

- 纯客户端插件：只读单位数据、只写本地面，不修改模拟数据、不发事件。
- 范围圈、单位信息只影响本机画面。

## 已知限制

- 单位信息暂不含“生命恢复速度”。

## 兼容

- 心灵终结 3.3.6（gamemd + Syringe 0.7.3 + Ares 3.0p1）
